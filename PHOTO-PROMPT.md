# Промт для бота, который делает фотографии товаров

Ниже — готовый текст задания. Копируйте его целиком, от строки «Задача» и до
конца файла, и отдавайте боту одним сообщением. Ничего дописывать не нужно:
там есть и список товаров, и требования к кадру, и правила приёмки.

---

## Задача

В каталоге интернет-магазина «Карапуз» 780 товаров. У 120 фотографии уже есть,
остальным **660 нужны снимки**: сейчас вместо фотографии показывается
нарисованная карточка. Нужно, чтобы у каждого товара была картинка **именно
того предмета, который написан в названии**, и чтобы весь каталог смотрелся
как съёмка одного магазина, а не сборная солянка.

Формат — **PNG без фона** (прозрачный альфа-канал). Карточка товара на сайте
может стоять на белом, сером или тёмном фоне, и вырезанный предмет ложится на
любой из них одинаково.

Репозиторий: `safarovmurod/swagger`, папка с картинками — `assets/products/`.

## Шаг 1. Возьми список товаров

Из корня репозитория:

```bash
node -e "
const { products } = require('./lib/data');
const need = products.filter(p => !String(p.image).includes('/assets/products/'));
const rows = need.map(p => [p.slug, p.name, p.brand, p.country, p.categoryName,
  p.subcategoryName, (p.colorOptions || []).join('|'), (p.materials || []).join('|'),
  p.ageGroup].join('\t'));
require('fs').writeFileSync('photos-todo.tsv',
  'slug\tname\tbrand\tcountry\tcategory\tsubcategory\tcolors\tmaterials\tage\n' + rows.join('\n') + '\n');
console.log('осталось снять:', rows.length);
"
```

Получится `photos-todo.tsv` — 660 строк, по одной на товар. Колонки:

| колонка | что это | как использовать |
|---|---|---|
| `slug` | адрес товара | **имя файла картинки** |
| `name` | название | главное: что именно в кадре |
| `brand`, `country` | бренд и страна | только для стиля, в кадр не попадают |
| `category`, `subcategory` | раздел каталога | тип предмета и порядок работы |
| `colors` | цвета через `\|` | берём **первый** |
| `materials` | материалы через `\|` | фактура: дерево, пластик, ткань |
| `age` | возраст ребёнка | размер и тип модели |

`photos-todo.tsv` — рабочий файл, в репозиторий его класть не нужно.

## Шаг 2. Работай по подкатегориям, а не подряд

Отсортируй список по колонкам `category` и `subcategory` и бери **по одной
подкатегории за раз — это ровно 20 товаров**. Сколько подкатегорий и сколько в
каждой осталось, покажет команда:

```bash
node -e "
const { products, categories } = require('./lib/data');
const need = products.filter(p => !String(p.image).includes('/assets/products/'));
categories.forEach(c => c.subcategories.forEach(sc => {
  const n = need.filter(p => p.subcategoryId === sc.id).length;
  if (n) console.log(c.name + ' → ' + sc.name + ': ' + n);
}));
"
```

Почему так:

- **внутри одной подкатегории все 20 картинок должны быть в одном стиле** —
  один ракурс, один масштаб, одна высота камеры. Они стоят рядом в списке, и
  разнобой виден сразу;
- **внутри одной категории все подкатегории должны быть в одном стиле** —
  «Кроватки», «Колыбели» и «Шкафы» это одна «Детская мебель»;
- закончил подкатегорию — прогнал проверки и сдал. Ошибка стиля тогда стоит
  20 картинок, а не 660.

## Шаг 3. Как называть файлы

Ровно так: `assets/products/{slug}.png`.

```
slug: pelenalnyy-komod-papaloni-bambino-121
файл: assets/products/pelenalnyy-komod-papaloni-bambino-121.png
```

Никаких `-1`, `-copy`, `-final`, никаких заглавных букв, пробелов, кириллицы и
других расширений. Имя файла — единственное, что связывает картинку с товаром:
ошиблись в имени — картинка не подключится, и её никто не увидит.

## Шаг 4. Каким должен быть кадр

- **PNG с прозрачным фоном**: за предметом ничего нет, альфа-канал чистый;
- **один товар целиком**, по центру, ничего лишнего рядом;
- **никакой тени и никакой подложки** — ни белого прямоугольника, ни серой
  плашки, ни «шахматки». Фон должен быть именно прозрачным, а не белым;
- **края чистые**: без белого ореола, бахромы и полупрозрачной каймы от
  неаккуратной вырезки;
- ровный рассеянный свет, без резких бликов и цветной подсветки;
- ракурс три четверти, предмет виден полностью и не обрезан краями кадра;
- предмет занимает 85–90% квадрата, по краям небольшой равный отступ;
- **квадрат 1:1, 800×800**;
- вес файла **до 150 КБ**, а лучше 60–100 КБ. PNG без сжатия весит мегабайт,
  поэтому прогоняй файлы через квантизацию (`pngquant --quality 65-90` или
  аналог) — на глаз разницы нет, а каталог из 780 картинок остаётся лёгким.

## Шаг 5. Картинка обязана совпадать с названием

Это главное требование. Проверяй по строке из `photos-todo.tsv`:

- **тип предмета** — из названия и подкатегории. «Пеленальный комод» — это комод
  с бортиками, а не кроватка; «Бустер» — это сиденье без спинки, а не автокресло
  группы 0+; «Молокоотсос» — не бутылочка;
- **цвет** — первый из колонки `colors`. Написано «Орех» — комод цвета ореха,
  а не белый;
- **материал** — из колонки `materials`: массив бука должен выглядеть деревом,
  ЛДСП — ламинированной плитой, пластик — пластиком;
- **возраст** — из колонки `age`: 0–6 месяцев это люлька, 3–7 лет — бустер;
- **бренд и страна** — только настроение и уровень модели. **Логотипов, надписей
  и фирменных знаков в кадре быть не должно.**

## Шаг 6. Промт для генератора изображений

Шаблон, подставляй значения из строки TSV:

```
Предметная фотография для каталога: {name}.
Категория: {category} → {subcategory}. Цвет: {первый из colors}.
Материал: {первый из materials}. Для ребёнка {age}.
Один предмет целиком в центре кадра, ракурс три четверти, высокая детализация,
ровный рассеянный свет, квадратный кадр 1:1.
Вырезанный предмет на полностью прозрачном фоне, без фона и без тени.
Без людей, без рук, без текста, без логотипов, без водяных знаков,
без коллажа, без рамок и подписей.
```

То же по-английски — многие генераторы понимают его точнее:

```
Product photo of {name in English or transliterated}, a {subcategory} for a {age}
child, {color} color, made of {material}. Single object centered, three-quarter
view, isolated cutout on a fully transparent background, no background, no shadow,
even diffused studio light, sharp focus, high detail, e-commerce catalog shot,
square 1:1 framing, PNG with alpha channel.
Negative: background, floor, shadow, reflection, people, hands, baby, text, letters,
logo, watermark, price tag, collage, multiple views, frame, border, white halo,
jagged edges, blurry, distorted.
```

Если генератор не умеет прозрачность — снимай на ровном белом и **аккуратно
вырезай по контуру** (rembg, «удалить фон» в редакторе), а потом проверяй края:
белой каймы остаться не должно.

Три заполненных примера:

```
Предметная фотография для каталога: Пеленальный комод Papaloni Bambino.
Категория: Детская мебель → Пеленальные комоды. Цвет: орех. Материал: массив бука.
Для ребёнка 0–5 лет. Один предмет целиком в центре, ракурс три четверти,
на полностью прозрачном фоне, без фона и без тени, 1:1.
```

```
Предметная фотография для каталога: автокресло группы 2-3 (бустер со спинкой).
Категория: Автокресла → Группа 2-3. Цвет: серый. Материал: текстиль и пластик.
Для ребёнка 3–12 лет. Один предмет целиком в центре, ракурс три четверти,
на полностью прозрачном фоне, без фона и без тени, 1:1.
```

```
Предметная фотография для каталога: молокоотсос электрический.
Категория: Кормление → Молокоотсосы. Цвет: белый. Материал: пластик и силикон.
Для ребёнка 0–12 месяцев. Один предмет целиком в центре, ракурс три четверти,
на полностью прозрачном фоне, без фона и без тени, 1:1.
```

## Шаг 7. Перевести в PNG старые 120 фотографий

В `assets/products/` уже лежат 120 готовых снимков в `.jpg` — они сделаны на
белом фоне. Их нужно привести к тому же виду: **вырезать фон и пересохранить
в PNG с тем же именем**.

```
было:  assets/products/kolybel-chicco-nanny-91.jpg
стало: assets/products/kolybel-chicco-nanny-91.png   ← .jpg удалить
```

Требования те же: прозрачный фон, чистые края без белого ореола, квадрат
800×800, до 150 КБ. Сам предмет не перерисовывай — это те же фотографии,
меняется только фон.

**Старый `.jpg` после этого удали.** Код возьмёт `.png`, даже если рядом лежит
`.jpg`, но два файла на один товар зря утяжеляют репозиторий.

## Чего в кадре быть не должно

Фон, пол, стена, отражение, тень · люди, руки, дети · текст, буквы, цифры,
логотипы, водяные знаки, ценники · коллаж и несколько ракурсов в одном кадре ·
интерьер и реквизит, не относящийся к товару · рамки и скруглённые углы ·
белый ореол и рваные края вырезки · размытие и искажения.

## Как сдавать работу

1. Клади файлы прямо в `assets/products/`. **Только `*.png`.** Служебные папки,
   кэш, исходники, архивы, файлы моделей и всё, что весит десятки мегабайт,
   в репозиторий не попадают — их приходится вычищать вручную.
2. Одна подкатегория — одна сдача (20 картинок).
3. После каждой подкатегории из корня репозитория:

   ```bash
   npm run generate   # переключает ссылки товаров на новые файлы
   npm run check      # проверяет данные, картинки и спецификацию
   npm run test:api   # сквозная проверка эндпоинтов
   ```

   Обе проверки должны быть зелёными. Только после этого коммит.
4. Если картинка какого-то товара не получилась — **лучше не класть файл вовсе**.
   Тогда у товара останется нарисованная карточка, и каталог не сломается.
   Плохая картинка хуже, чем её отсутствие.

## Как проверить себя

```bash
node -e "
const fs = require('fs');
const { products } = require('./lib/data');
const slugs = new Set(products.map(p => p.slug));
const files = fs.readdirSync('assets/products');
const wrong = files.filter(f => !/\.(png|jpg)$/i.test(f) || !slugs.has(f.replace(/\.(png|jpg)$/i, '')));
const heavy = files.filter(f => fs.statSync('assets/products/' + f).size > 150 * 1024);
const png = new Set(files.filter(f => f.endsWith('.png')).map(f => f.slice(0, -4)));
const both = files.filter(f => f.endsWith('.jpg') && png.has(f.slice(0, -4)));
console.log('файлов:', files.length, '· png:', png.size, 'из 780');
console.log('имя не совпадает со slug:', wrong.length, wrong.slice(0, 10));
console.log('тяжелее 150 КБ:', heavy.length, heavy.slice(0, 10));
console.log('остался лишний .jpg рядом с .png:', both.length, both.slice(0, 10));
"
```

Все четыре строки должны быть чистыми: лишних имён нет, тяжёлых файлов нет,
дубликатов `.jpg` рядом с `.png` нет.
